# IoT26 TeamJ HW05- Raspberry Pi Home Assistant

## 1. Objective

- Starting and setting up Home Assistant on Raspberry Pi, and creating a simple example for home automation.

## 2. Environment

- Raspberry Pi 5
- Raspberry Pi OS (64-bit)
- Python 3
- gpiozero library
- Home Assistant

## 3. Circuit

### Components
- Raspberry Pi
- LED x2
- Breadboard

## 4. Files

- Python source code is included in the repository.
- Result images and GIF files are included in the result folder.

## 5. Issues / Troubleshooting

### 1. Wi-Fi Connection Issue

Cause
- Existing Wi-Fi settings did not work properly, requiring Wi-Fi reconfiguration.

Solution
- Formatted the SD card, reinstalled Raspberry Pi OS, and configured Wi-Fi again.

## 6. Conclusion

Through this project, I learned how to install and configure Home Assistant on Raspberry Pi and create a simple home automation system. I also understood how different devices can be integrated and controlled within a single IoT environment using Home Assistant.

During the project, Wi-Fi connection issues occurred again, and solving them emphasized the importance of stable network settings and proper Raspberry Pi environment configuration.

In addition, I was able to control Raspberry Pi GPIO pins through the Home Assistant web interface and implement simple automation functions such as automatically turning LEDs on and off at specific times.

As a result, this project provided experience in combining Home Assistant with Raspberry Pi to understand the basic structure and operation of IoT-based home automation systems.
